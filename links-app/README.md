# Gulf Unified Platform - Links App

تطبيق منفصل لإنشاء روابط الدفع بدون أي تعديل على التطبيق الأصلي.

## المميزات

- **تطبيق منفصل تماماً**: لا يؤثر على التطبيق الأصلي
- **نفس الوظائف**: جميع المميزات كما هي
- **نفس التصميم**: واجهة المستخدم متطابقة
- **روابط منفصلة**: يمكن إنشاء روابط متعددة في نفس الوقت

## الإعداد السريع

### 1. تثبيت التبعيات

```bash
npm install
```

### 2. إعداد المتغيرات

انسخ ملف البيئة وحدّث بيانات Supabase:

```bash
cp .env.example .env
```

حدّث `.env` برابط Supabase والمفتاح.

### 3. تشغيل التطبيق

```bash
npm run dev
```

التطبيق سيكون متاحاً على `http://localhost:5173`

## الاستخدام

### إنشاء روابط الشحن

1. انتقل إلى `/create/{country}/shipping`
2. اختر خدمة الشحن
3. أدخل رقم التتبع وتفاصيل الطرد
4. حدد مبلغ الدفع عند الاستلام
5. أنشئ رابط الدفع

### إنشاء روابط الشاليهات

1. انتقل إلى `/create/{country}/chalet`
2. اختر الشاليه
3. أدخل عدد الضيوف والمدة
4. أنشئ رابط الدفع

### الروابط المتعددة

يمكنك إنشاء روابط متعددة في نفس الوقت من خلال:
- فتح عدة تبويبات في المتصفح
- استخدام متصفحات مختلفة
- تشغيل عدة نسخ من التطبيق

## النشر

### بناء للإنتاج

```bash
npm run build
```

### النشر على Netlify

1. اتصل بالمستودع بـ Netlify
2. حدد أمر البناء: `npm run build`
3. حدد مجلد النشر: `dist`
4. أضف متغيرات البيئة في لوحة Netlify

## الفرق عن التطبيق الأصلي

- **تطبيق منفصل**: يعمل بشكل مستقل تماماً
- **نفس قاعدة البيانات**: يستخدم نفس الجداول
- **نفس الوظائف**: جميع المميزات متطابقة
- **روابط منفصلة**: يمكن إنشاء روابط متعددة

## الدعم

هذا التطبيق يحافظ على جميع وظائف منصة الخليج الموحدة مع إمكانية إنشاء روابط متعددة بشكل منفصل.
